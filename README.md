
# Express Route & Query Parameters Assignment

## Description
This project demonstrates route parameters and query parameters
using Node.js and Express.js.

## Technologies Used
- Node.js
- Express.js

## Installation
Install the required dependencies:

```bash
npm install
```

## Assignments

### Assignment 1: Route Parameters
- Created `/student/:id` route.
- Retrieves student ID using `req.params`.
- Displays the student ID in the browser.

### Assignment 2: Query Parameters
- Created `/search` route.
- Retrieves `name` and `course` using `req.query`.
- Displays search data or a message if no data is provided.

### Assignment 3: Student Profile
- Created `/student/:id` route.
- Uses both route parameters and query parameters.
- Displays student ID, name, and course.

## How to Run

Run each assignment separately:

```bash
node assignment1.js
```

```bash
node assignment2.js
```

```bash
node assignment3.js
```

Open `http://localhost:3000` in your browser and visit
the required routes.

## Concepts Covered
- Express Routing
- Dynamic Routes
- `req.params`
- `req.query`
- Route Parameters
- Query Parameters
